# TopoFormer Membrane Training

This repository contains a semester-long CMSE 802 research software project focused on retraining and evaluating TopoFormer with additional membrane-transporter protein-ligand data.

## Project Goal

TopoFormer is a machine-learning model for protein–ligand binding-affinity prediction. This project asks whether enriching its existing training dataset with additional membrane-transporter complexes can improve predictive performance for transporter systems, with particular interest in Organic Anion Transporting Polypeptides (OATPs).

The primary software goal is to develop a reproducible workflow for:

1. Preparing baseline and membrane-transporter-enriched training data,
2. Generating TopoFormer-compatible features,
3. Retraining the model, and
4. Comparing model performance using held-out test data.

## Repository Structure

- `topoformer_membrane/` — Python code developed for the project
- `examples/` — small example input data for exercising the prototype
- `results/` — example output generated by the prototype
- `paper/` — project proposal and eventual JOSS-style manuscript
- `scripts/` — command-line and repository utility scripts
- `guides/` — supporting documentation from the course template
- `environment.yml` — software environment specification
- `makefile` — convenience commands for common development tasks

Large training datasets, generated features, and model outputs will not be stored directly in this repository due to size limitations. Small example datasets and outputs are included to demonstrate the workflow.

## Project Status

The repository currently provides a working, tested analysis workflow for processing TopoFormer protein-ligand binding-affinity predictions. The implemented functionality includes:

- Parsing transporter, ligand, and AlphaFold3 replicate identifiers from TopoFormer output.
- Aggregating structure-level predictions into ligand-level summary statistics.
- Recording the number of available structures per ligand, including incomplete replicate sets.
- Checking for overlapping identifiers between training and test datasets.
- Running automated unit tests and a reproducible reference validation.
- Generating HTML API documentation using pdoc.

The workflow has been demonstrated using 1,082 OATP1B3 structure-level predictions representing 109 ligands. A smaller, self-contained example containing 28 predictions for three ligands is included for independent reproduction.

The broader research goal is to retrain TopoFormer using membrane-transporter-enriched datasets and compare predictive performance against the original model. Dataset preparation, retraining, and experimental accuracy evaluation are planned components and are not yet implemented in this repository.

## Planned Workflow

The broader project will use the existing TopoFormer training and evaluation workflow as a baseline. Additional membrane-transporter training examples will then be incorporated, followed by model retraining and comparison against the original model.

The current prototype provides the analysis layer needed to summarize TopoFormer predictions consistently before later model comparisons are performed.

## Installation and Setup

Requirements: Git, Conda or Miniforge, and Make.

### Fresh Installation

Clone the repository:

    git clone https://github.com/lrg12345/TopoFormer-Membrane-Training.git
    cd TopoFormer-Membrane-Training

Create the project environment:

    make init

Activate the environment:

    conda activate ./.envs

All subsequent commands should be run from the repository root with this environment active.

### Verify the Installation

    make help
    make check
    make validate
    make docs

Expected results:

- `make help` lists the available commands.
- `make check` runs Ruff and 10 pytest tests.
- `make validate` runs the OATP1B3 reference regression test.
- `make docs` generates HTML API documentation in `docs/`.

Open `docs/index.html` in a browser to view the generated documentation.

The included example does not require HPCC access, private research data, GPU resources, or a trained TopoFormer model.

## Running the Prototype

A small example dataset is provided in:

`examples/1b3_example_predictions.csv`

To run the prototype:

```bash
python -m scripts.summarize_predictions \
  examples/1b3_example_predictions.csv \
  results/1b3_example_summary.csv
```

The prototype reads structure-level TopoFormer prediction results and produces one summary row per transporter-ligand pair. The output includes:

- transporter identifier
- ligand name
- number of available structure predictions
- mean predicted pK
- median predicted pK
- standard deviation of predicted pK
- minimum and maximum predicted pK
- mean preprocessing time
- mean inference time

The included example contains 28 structure-level predictions for three OATP1B3 ligands and produces three ligand-level summary rows.

A larger OATP1B3 dataset containing 1,082 structure-level predictions across 109 ligands was also processed successfully using the same workflow.


## Reproducibility Walkthrough

The included OATP1B3 example provides a self-contained way to reproduce the analysis workflow without access to private research data.

From the repository root, with the project environment activated, run:

    python -m scripts.summarize_predictions examples/1b3_example_predictions.csv results/1b3_reproduced_summary.csv

Expected terminal output:

    Read 28 structure-level predictions.
    Summarized 3 transporter-ligand pairs.
    Wrote summary to: results/1b3_reproduced_summary.csv

The generated CSV contains one row per ligand, including prediction statistics and runtime measurements. Representative expected values are:

| Ligand | Structures | Mean predicted pK |
| --- | ---: | ---: |
| 17-b-estradiol | 8 | 5.263052 |
| 5-carboxyfluoresceindiacetate | 10 | 6.207954 |
| acarbose | 10 | 4.938985 |

Compare the reproduced output with the committed reference using:

    make validate

This command independently regenerates the summary from the example input and checks numerical agreement with the committed reference. A successful run reports one passing test. The generated `results/1b3_reproduced_summary.csv` file is not required for the automated validation.

## Validation

The project includes a regression validation based on the included OATP1B3 example dataset. The validation regenerates the ligand-level summary from `examples/1b3_example_predictions.csv` and compares it against the committed reference output in `results/1b3_example_summary.csv`.

Run the validation with:

    make validate

A successful validation should report one passing test and confirm that:

- 28 structure-level TopoFormer predictions are processed,
- 3 transporter-ligand summary rows are produced,
- replicate counts are preserved as 8, 10, and 10,
- calculated prediction and runtime statistics match the committed reference output within floating-point tolerance.

Validation is expected to fail if required input columns are missing, prediction identifiers do not follow the expected naming convention, or changes to the aggregation logic produce results that no longer match the reference output.

### Assumptions and Limitations

The current workflow assumes TopoFormer output contains the columns `pdbid`, `pK_predicted`, `t_prep_s`, and `t_inf_s`, and that identifiers follow the pattern `<transporter>_<ligand>_AF3_<replicate>`. The workflow does not assume that every ligand has the same number of successful structure predictions; incomplete replicate sets are preserved through the `n_structures` field.

This validation checks the correctness and reproducibility of post-inference processing. It does not validate the scientific accuracy of TopoFormer affinity predictions against experimental measurements. The current reference case is limited to OATP1B3 and has not yet been extended to OATP1B1, OATP2B1, or other transporter families.
